## 零食保质期管理 — 部署指南（Render 零成本方案）

### 架构
```
手机浏览器 → GitHub Pages (前端)
                ↓ API 调用
           Render (后端 + 数据库)
                ↓ 每天 9:00 自动检查
           Web Push → 手机通知

cron-job.org → 每 5 分钟 ping Render → 防止休眠
```

### 第一步：部署后端到 Render（完全免费）

1. 注册 https://render.com（用 GitHub 账号登录）
2. 先把 `snack-backend/` 目录推送到你的 GitHub 仓库
3. Render 首页点 **New + → Web Service**
4. 选择你的 GitHub 仓库，Render 会自动检测 `render.yaml`
5. 点 **Deploy Web Service**，等 2-3 分钟
6. 部署完成后你会得到地址，如 `https://snack-tracker-api.onrender.com`

### 第二步：防休眠（cron-job.org，免费）

1. 注册 https://console.cron-job.org
2. 创建新的 Cronjob：
   - URL：`https://你的render地址.onrender.com/api/health`
   - 执行间隔：**每 5 分钟**
   - 点 Create
3. 这样 Render 永远不会休眠，推送 100% 可靠

### 第三步：配置前端连后端

打开 `index.html`，找到这两行：

```js
const API_URL = '';
const VAPID_PUBLIC_KEY = '';
```

改成（你的 render 地址 + VAPID 公钥）：

```js
const API_URL = 'https://snack-tracker-api.onrender.com';
const VAPID_PUBLIC_KEY = 'BIJwtedMxxYAEWXsVoVUUa0RmmK5bE9d2-BR2PSvCGUAGGnhURZsnY0sX-4jUpndS5GO4GN9X_RIFoGSf43hWXw';
```

推送到 GitHub Pages，完成！

### 第四步：手机打开，测试推送

1. 手机打开 `https://你的用户名.github.io/snack-tracker/`
2. 浏览器会提示是否允许通知 → **允许**
3. 录入几条零食，确保有即将过期的
4. 第二天 9:00 会自动推送通知到手机
