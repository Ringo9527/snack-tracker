## 微信小程序版 — 部署指南

### 准备工作

1. 注册微信小程序：https://mp.weixin.qq.com
2. 下载微信开发者工具：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
3. 克隆仓库到本地

### 三步部署

**第一步：替换 AppID**

打开 `project.config.json`，把 `"appid"` 改成你小程序的 AppID（在小程序后台 → 开发 → 开发设置 里找）

**第二步：开通云开发**

1. 微信开发者工具打开项目
2. 点击工具栏「云开发」图标
3. 开通云开发（免费额度够用）
4. 记下环境 ID，打开 `app.js` 把 `'你的环境ID'` 换成实际的

**第三步：配置数据库**

在云开发控制台 → 数据库���
- 创建集合 `snacks`
- 权限选「仅创建者可读写」

**第四步：配置定时推送**

在云开发控制台 → 云函数：
1. 右键 `scheduledCheck` → 上传并部署
2. 右键 `subscribe` → 上传并部署
3. 在云函数 `scheduledCheck` 的「触发器」中添加定时触发器：
   - 触发周期：每天 09:00

**第五步：配置订阅消息**

1. 小程序后台 → 功能 → 订阅消息 → 选用模板
2. 搜索「食品保质期提醒」或自定义模板
3. 把模板 ID 填入 `pages/list/list.js` 的 `subscribeMsg` 函数
